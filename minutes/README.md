# Library Carpentry Governance Meeting Minutes

This directory contains meeting minutes for the Library Carpentry Governance Committee.

There is a gap in this repository between the 2022 and 2026 minutes. During much of that period, the Library Carpentry Curriculum Advisory Committee carried out many of the operational responsibilities of the Governance Committee. The Curriculum Advisory Committee and Governance Committee formally combined in 2025.

Meeting minutes from the intervening period are available in the [Library Carpentry Curriculum Advisory Committee repository](https://github.com/LibraryCarpentry/curriculum-advisors/tree/main/minutes).

Beginning in 2026, minutes for the combined Library Carpentry Governance Committee are maintained in this directory.
